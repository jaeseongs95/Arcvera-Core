# R39 압축 변경 프리릴리스

R39는 정식 발행·동결된 [R38 (`v0.167.0-r38.20261106`)](https://github.com/jaeseongs95/opendiy-codex/releases/tag/v0.167.0-r38.20261106)을 기반으로 압축 동작만 변경하는 프리릴리스 후보입니다. 버전은 `0.167.0+native-r39.20261107`입니다. 압축 외에 개발 중이던 다른 미완성 기능은 포함하지 않습니다.

최종 release 실행 파일 5개와 전체 패키지 조립·격리 실행검사 15개를 완료했습니다. 최종 실행본의 Desktop 공동시험과 정식출시 수용은 아직 미완료입니다. 이번 대상은 시험용 프리릴리스이며, 발행 상태는 [rc.1 릴리스 페이지](https://github.com/jaeseongs95/opendiy-codex/releases/tag/v0.167.0-r39.20261107-rc.1)에서 확인하십시오. 기존 설치나 공유 서버를 자동으로 전환하지 않습니다.

## 압축 기준

압축의 목적은 완료된 작업의 원문을 모델 문맥에서 덜어내고, 현재 상황을 이어갈 수 있는 요약을 남기는 것입니다. 적용하는 요약 기준은 다음과 같습니다.

> 현재 상황을 유지하고 이어서 작업할 수 있게 요약해 줘. 사용자의 요청 원문과 목표, 확정된 결정과 그 이유, 수정한 파일 경로와 핵심 변경, 실행한 검증과 결과(실패 메시지 포함), 진행 중인 작업과 남은 할 일, 사용자가 준 제약과 피드백은 빠짐없이 남기고, 끝난 탐색 과정과 긴 도구 출력은 결론만 남겨.

완료된 작업의 원문·과정·변경 및 검증 상세는 활성 문맥에서 제외합니다. 미완 작업이 완료 결과에 직접 의존할 때만 필요한 결론과 근거 위치를 짧게 남깁니다. 요청·결정·변경·검증·제약의 보존 기준도 현재 미완 작업에 필요한 범위에 적용합니다.

## 변경 범위

- 압축 전 작업의 사용자·hook·에이전트 원문 메시지를 압축 결과 뒤에 자동으로 다시 첨부하는 동작을 중단합니다. 현재 미완 요청의 필요한 원문은 요약 지침으로 보존하도록 합니다.
- 현재 진행 상태와 남은 작업을 이어갈 수 있도록 위 요약 기준을 적용합니다.
- 해석할 수 없는 압축 상태, 저장된 원본 이력, 정본·영속 제어 정보와 진행 중인 백그라운드 작업의 후속 메시지는 보존합니다.
- 로컬 압축 결과가 비어 있으면 이전 assistant 응답을 대체 요약으로 재사용하지 않고 오류로 처리합니다.

모델에 전달하는 압축 문맥을 줄이는 변경이며 저장된 원본 대화 이력을 삭제하는 기능은 아닙니다.

## 패키지 사용 안내

전체 ZIP 사용을 권장합니다. 폴더 구조를 유지해 압축을 풀면 helper와 음성 등 추가 리소스를 함께 보존할 수 있습니다.

개별 `codex.exe` 또는 `codex-app-server.exe`를 사용할 때는 같은 릴리스의 `codex-code-mode-host.exe`를 **실제로 실행하는 EXE와 같은 폴더**에 원래 이름 그대로 두어야 합니다. `functions`를 포함한 code-mode 도구는 이 helper가 필요하며, 누락되면 host 시작이 `os error 2`로 실패할 수 있습니다. CLI가 기존 서버에 접속한다면 실제 서버 실행 경로와 그 옆의 helper도 확인하십시오.

R38의 개별 자산에는 이 helper가 없으므로 R38 전체 ZIP에서 가져와야 합니다. 동결된 R38 릴리스는 변경하지 않습니다. R39 프리릴리스에는 이 helper를 개별 자산으로 구성했습니다. 전체 ZIP과 CLI·App Server·code-mode helper·체크섬·사용 안내의 정확한 6개 자산은 rc.1 릴리스 페이지에서 확인하십시오. 개별 EXE와 이 helper만으로 음성 등 추가 리소스까지 구성되지는 않으므로 해당 기능은 전체 ZIP을 사용하십시오.

## 검증 상태와 한계

고정 소스 `c4399dce957bb63fe1fdc276aa4306c06f6cf47f`의 `dev-small` compact 통합시험은 208개 통과·0개 실패·Windows 조건부 제외 2개입니다. 기존 제외 3개 중 수동 compact 오류 시험은 현행 원오류 보존 계약에 맞게 복구·재활성화해 실제 통과했습니다. 원 실패와 제외 사유, 후보별 결과는 [시험 상태](TESTING.md)에 구분합니다. 같은 고정 소스의 최종 release 실행본으로 CLI·App Server·helper·launcher·음성 구성요소의 격리 실행검사 15개를 통과했습니다. 전체 패키지는 payload 55개와 영수증 1개로 구성됩니다. 개발 후보의 Desktop 공동시험 결과는 최종 실행본의 공동시험을 대신하지 않으며, 최종 실행본의 GUI 1~5번과 정식출시 수용은 미완료입니다. 공개 후 자산 다운로드 검증은 rc.1 릴리스 기록에서 확인하십시오. R38의 기존 검증 결과를 R39의 압축 변경이 통과한 근거로 사용하지 않습니다.

요약에서 어떤 내용을 남기고 줄이는지는 모델의 판단에 의존합니다. 실제 모델이 필요한 내용을 빠짐없이 보존하면서 완료된 탐색을 충분히 줄이는지에 대한 품질 검증은 아직 수행하지 않았습니다. 코드의 재첨부 방지 동작이나 시험 통과만으로 이 요약 품질을 보장하지 않습니다.
