# R33 개발 후보의 출처와 검증 범위

현재 고정 원본은 `76c0a7ab3b971918cd3d9f30daf8e1344941359c`, 이전 공개 기준은 `5537d7bf4f0730969dfaf1c1ed876acb8920a5e1`다. R33 개발 중 소스이며 전체 Cargo 버전은 여전히 `0.166.0+native-r32.20261101`이다. R33 제품 버전 스탬프·최종 통합 실행 파일·설치·릴리스는 완료하지 않았다.

비강제 전환은 drain 중 재요청 시 강제 종료로 승격되는 결함(F2)이 확인되어 후속 수정 전 배포 불가 상태다. 아래의 앞선 정적 검토 결과와 캐시·메시지 재생 시험을 이 결함의 해소나 현재 후보의 배포 승인으로 해석하지 않는다.

## 포함한 변경

기존 메시지 재생 3파일을 보존하고 `278f41f74f26b72cd2f3bf068400d8454a00ff75` 이후 13경로를 더했다. 비강제 갱신 `update --from-cli --no-force`, 수동 상태 조회 `status --json`, 캐시 진단의 명시적 설정 선택, 관련 시험과 [캐시 관측 문서](native-cli-r33-cache-observation.ko.md)를 포함한다. 새 문서는 exporter의 명시적 source prefix로 포함해 Git blob·고지·inventory 검사를 받는다.

비강제 갱신 보완은 기존 updater에 종료 요청을 보내지 않고 두 패키지 root의 기존 installer 락을 확인하도록 작성됐다. 실패 시 이번 명령이 강제 종료나 선택 교체를 새로 유발하지 않는 범위이며, 독립적인 기존 updater 작업을 영구 금지하는 보장은 아니다. 상태 조회의 `stopped`는 원자적 설치 상태나 안전한 갱신 시점을 보증하지 않는다. 이 설명은 소스의 의도와 정적 검토 범위이며 최종 후보의 실제 daemon 동작 검증을 대신하지 않는다.

캐시 진단은 일반 배치 logging과 별도 파일의 `response=true`, `wire=true` 선택으로 응답·wire 관측을 함께 켠다. 환경변수의 추가 선택을 요구하지 않으며, 기존 환경변수 단독 선택은 다른 tracing consumer를 위해 유지한다. 기본값·공유 logging 설정·사용자 설정 파일은 자동 변경하지 않는다. 이 소스 공개 과정에서 운영 설정이나 실행 중 프로세스를 변경하지 않았다.

캐시 설정 red는 logging·response·wire가 선택되고 기존 환경변수가 없는 조합과 시작 시 모드 고정의 실패를 확인했다. 현재 후보의 진단 시험은 명시적 설정과 기존 환경변수의 조합, 기본값·엄격한 설정 해석·프로세스 시작 후 불변성을 확인한다. HTTP/WS 부모 시험은 `wire=false/true`와 환경변수 없음·`0`·`1`의 6조합에서 실제 생산자부터 응답 해석·완결 배치까지 통과했다.

현재 후보의 캐시 진단 시험 실행 파일 SHA-256은 `f21e645420b87b1b0ae288d20f43640c259d52b130f0bd7c411c7fa1ace46745`, HTTP/WS 경계 시험 실행 파일은 `1c32736cb19d7854bdf0c8983de828c510e9fa701cf6958a9f4d10d829b81f36`이다. 각 실행 메타데이터의 소스 커밋·SHA-256을 실제 파일과 대조했고, 로그의 실행 이름·개수·결과를 직접 확인했다. 원시 로그·실행 파일·개인 경로는 공개하지 않는다. 이전 재생 시험의 상세는 [재생 검증 기록](r33-replay-verification.ko.md)에 보존한다.

## 공개 출처 검증

공개 작업사본에서 아래 두 명령을 실제 실행했고 각각 종료 코드 0이었다.

```sh
python -B scripts/source-import/verify.py
python -B scripts/source-import/test_verify.py
```

소스 9,403개·공식 대비 수정 533개·Cargo manifest 171개·작업공간 구성원 165개·경로 입력 294개·Rust literal include 132개·내장 프롬프트 38개를 확인했다. Windows 프롬프트 원시 해시도 통과했다. 도구 시험은 18개 중 17개 통과·실제 심볼릭 링크 생성 1개 건너뜀이며, R33 Rust·Markdown 고지와 나머지 R32 기본 고지의 보존 검사를 포함한다.

출처 검사에는 inventory·공식 대비 patch·프롬프트 catalog의 해시 결속, 각 공개 파일에서 고지를 제외한 원본 SHA-256·Git blob, 로컬 경로 의존성과 literal include가 포함된다. 기존 R32 고지와 재생 3파일의 R33 고지는 보존하고 새 델타 13경로만 R33 고지에 추가했다. 루트 LICENSE·NOTICE·README 두 파일과 내장 프롬프트 38개의 바이트 해시는 유지한다. 이 검사는 Rust 빌드나 제품 runtime을 실행하지 않는다.

F2는 drain 중인 기존 서버에 비강제 종료 요청을 다시 보내면 그 요청이 두 번째 Forceable 종료 신호로 처리돼 drain을 건너뛰는 경계다. 후속 수정과 해당 경계의 실제 회귀 검증 전에는 배포할 수 없다.

최종 통합 CLI·daemon runtime, 비강제 갱신의 실제 installer 경쟁·grace 실패·구 updater와의 공동 동작, 실제 사용 환경의 전환·재개·부하 효과, 설치·릴리스는 미검증이다. 진단 계층과 로컬 경계 시험의 통과나 앞선 정적 검토를 전체 R33 제품 완료로 확대하지 않는다.
