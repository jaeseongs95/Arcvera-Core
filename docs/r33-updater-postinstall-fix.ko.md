# R33 Windows 자동업데이트 수정 후보

## 공개판과 수정 후보

공개판 `v0.166.0-r33.20261102`의 개발 소스는 `36ae395a552fd55962e19409cbf29b1fdf03b0ec`입니다. CLI·별도 앱 서버·휴대용 패키지를 포함한 자산 5개를 공개했고, 실제 익명 다운로드 해시와 이 PC의 설치 파일·바로가기를 대조했습니다.

설치 후 새 독립감사에서 자동업데이트 결함 2건을 확인했습니다. 따라서 공개·설치 완료와 자동업데이트 정상 동작을 구분합니다. 기존 공개 파일과 태그는 보존합니다.

수정 후보의 개발 소스는 `bd2ed8ec7854d64905caa67d0f77758e758a930c`입니다. 이 문서의 검증은 해당 소스와 격리 시험에 한정됩니다. 수정한 패키지의 공개·실제 설치·생산 예약 실행은 아직 완료하지 않았습니다.

## 확인한 원인과 수정

| 결함 | 확인한 경계 | 수정 |
| --- | --- | --- |
| 같은 사용자 예약을 소유권 충돌로 오인 | Windows 예약 작업이 반환한 짧은 사용자 이름과 전체 계정 이름은 문자열이 다르지만 SID는 동일 | 계정 이름을 SID로 해석해 비교. 다른 SID·해석 실패·높은 실행 권한은 계속 거부 |
| 한글 경로에서 숨김 실행 실패 | PowerShell 5.1의 출력이 UTF-8이 아니어서 native CLI의 콘솔 전달과 충돌 | 직접 실행한 업데이트 프로세스의 출력 인코딩을 UTF-8로 고정. 도트 소싱한 호출자의 인코딩은 보존 |

예약의 정확한 실행 파일·인자와 `Limited` 권한 검사는 유지했습니다. 일반 출력 오류나 업데이트 실패를 무시하도록 바꾸지 않았습니다. 사용자 인증·설정·DB와 기존 패키지, 공유 daemon도 수정 대상에서 제외했습니다.

## 실제 시험과 남은 범위

- 같은 최종 시험으로 원본 helper의 UTF-8 해석 실패와 숨김 실행 종료 코드 1을 재현했습니다. 수정 helper에서는 한글 경로가 JSON에 보존되고 숨김 실행이 종료 코드 0으로 끝났습니다.
- 위 시험의 native CLI는 공개 R33 실행 파일과 같은 SHA-256입니다. 재컴파일 결과가 아니라 기존 실행 파일과 수정 helper를 조합한 격리 시험입니다.
- 오류 입력에서는 수정 후에도 helper가 종료 코드 1과 오류 JSON을 반환했습니다.
- 기존 업데이트 시험 13건이 통과했습니다. 예약 소유자 시험은 운영체제의 SID 해석을 사용하되 예약 작업 명령은 mock으로 대체했습니다. 같은 시험을 원본 helper에 적용하면 동일 사용자의 짧은 이름을 거부하는 경계에서 실패했습니다.
- 구현에 참여하지 않은 새 감사자가 소스와 원시 시험 근거를 직접 확인했습니다. 판정은 소스·격리시험 범위의 PASS이며 실제 자동업데이트 완료 판정은 아닙니다.

실제 예약 작업의 재등록·비활성화·실행 결과 0과 그 실행에 연결된 업데이트 결과를 추가로 확인해야 합니다. 후속 패키지와 소스·실행 파일 버전의 연결, 다운로드 해시, 설치 후 검증도 남아 있습니다. 기존 R33 자산을 같은 이름으로 덮어쓰지 않습니다.

OpenDIY Desktop 1.0.2와 공개 R33의 공동시험은 별도로 수행했습니다. 이번 수정 후보를 실제 설치한 뒤의 공동시험, 실제 모바일 연결, 장시간 부하와 원래 메모리 증가 문제의 해결 여부는 이 결과로 보증하지 않습니다.
