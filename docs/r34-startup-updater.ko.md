# R34 개발 후보

R34는 아직 공개·설치되지 않았습니다. 공식 기반은 0.166.0이며 기존 R33 자산은 보존합니다.

- 시작 오류: daemon 버전 불일치 오류가 먼저 생성된 뒤 ErrorHook을 설치해 시작이 중단되는 순서를 수정합니다. 같은 프로세스의 재진입에서 panic 복구·진단 호출이 누적되던 책임도 하나로 통합했습니다. 동시 초기화·복구 경로 회귀시험을 추가했으며 실행 검증은 남아 있습니다.
- 자동업데이트: 같은 Windows SID의 작업 소유자를 충돌로 오인하는 문제와 PowerShell 5.1 출력 인코딩을 수정합니다. 격리 fixture 13개는 통과했으며 실제 예약 실행·설치 검증은 남아 있습니다.
- 공식 선별 반영: `6ff7f31`의 이력 로딩·삽입 중 불필요한 렌더링 생략과 `e75e4af`의 기본 키맵 캐시 재사용을 체리픽했습니다. 이력 보유 한도와 사설 키맵 해석은 보존하며 회귀시험은 진행 전입니다.

공식 prerelease 전체 이식이나 기존 R28 공유 daemon 교체는 이번 변경에 포함하지 않습니다. Desktop 담당과 CLI·서버 버전 및 daemon 상태 계약을 유지하고, 최종 실행본 공동시험과 새 독립감사 뒤 별도 R34로 공개·설치합니다. 소스 브랜치를 PR로 제공하며 main은 자동 병합하지 않습니다.
