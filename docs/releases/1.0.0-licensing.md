## English

The project release uses AGPL-3.0-or-later. Independently licensed source retains its original notices and rights. This record selects the alternatives below from the exact 1,296-package Cargo.lock source superset delivered with build source `5c789f501b5cc82187976a1e916d239e0710415a`. All 54 distinct declarations are covered. An `AND` obligation is retained; legacy Cargo slash declarations are treated as alternatives and identified by their original spelling. Package declarations do not override additional file-level licenses. Original source archives, 2,551 copied original notice texts and supplemental notices remain in the complete package. This table is not an exact inventory of code linked into the executable.

The ten MPL-only packages retain their original MPL-2.0 source and notices. For their combination with this AGPL Larger Work, the covered source is additionally distributed under AGPL-3.0-or-later pursuant to MPL section 3.3. The delivered complete-source inspection found no actual Exhibit B incompatible-source declaration; the standard license's example Exhibit B is not such a declaration. See `source/dependencies/manifests/mpl-source-review.json`. This treatment follows the [MPL text](https://www.mozilla.org/en-US/MPL/2.0/) and [Mozilla's combination guidance](https://www.mozilla.org/en-US/MPL/2.0/FAQ/#q14-may-i-combine-mpl-licensed-code-and-lgpl-licensed-code-in-the-same-executable-program).

GLib/GStreamer remain separate LGPL shared libraries. Their exact source, notices and build scripts are supplied; recipients retain library modification, interface-compatible replacement and reverse engineering to debug modifications. Unchanged OpenAI helpers retain Apache/other upstream terms; matching complete upstream source is included. The byte-matched ripgrep 15.2.0 source, locked dependency superset and PCRE2 10.45 source retain their own original licenses. Microsoft vcruntime140.dll retains its separate redistributable terms and signed retail identity. No project license claim is made over it. Windows system/toolchain components are not relicensed by this project.

The 23 original missing-notice questions and their source-specific dispositions are preserved in `source/dependencies/manifests/notice-dispositions.json`. Explicit uncertainties remain: the Android AAR producer revision and fxhash extraction revision were not established; absent standalone wrapper copyright notices were not invented. Cargo publisher grants and full original source are distinguished from separately recovered historical/reference notices. Native/bit-identical rebuilding and complete restore extraction were not run. The complete source README explains restoration and actual build controls. Network operators must additionally provide the source offer required by AGPL section 13 in their actual user interface.

## 한국어

프로젝트 릴리스에는 AGPL-3.0-or-later를 적용하며 별도 라이선스 소스의 원 고지와 권리를 유지합니다. 아래 표는 빌드 소스 `5c789f501b5cc82187976a1e916d239e0710415a`와 함께 제공하는 정확한 Cargo.lock 소스 1,296개 패키지의 대안 선택 기록입니다. 서로 다른 선언 54종 전체를 포함합니다. `AND` 의무를 유지하며 과거 Cargo의 슬래시 선언은 대안으로 해석하되 원 표기를 보존합니다. 패키지 선언이 파일별 추가 라이선스를 덮어쓰지 않습니다. 전체 패키지는 원 소스, 복사한 원 고지 2,551개와 보충 고지를 유지합니다. 이 표는 실행 파일에 연결된 코드의 정확한 목록을 뜻하지 않습니다.

MPL 단독 패키지 10개의 원 소스·고지는 MPL-2.0을 유지합니다. 이 AGPL Larger Work와 결합해 배포하는 해당 소스는 MPL 제3.3조에 따라 AGPL-3.0-or-later로도 추가 배포합니다. 제공한 전체 소스 검사에서는 실제 Exhibit B 비호환 선언을 찾지 못했습니다. 표준 라이선스 본문에 포함된 Exhibit B 예시 자체를 비호환 선언으로 판정하지 않습니다. `source/dependencies/manifests/mpl-source-review.json`, 위 Mozilla 공식 약관과 결합 안내를 참조하십시오.

GLib/GStreamer는 별도의 LGPL 공유 라이브러리를 유지합니다. 정확한 소스·고지·빌드 스크립트를 제공하며 수정·인터페이스 호환 라이브러리 교체·수정 디버깅을 위한 역공학 권리를 보존합니다. 변경하지 않은 OpenAI 도우미는 원 Apache 등 upstream 권리를 유지하며 대응하는 전체 원 소스를 제공합니다. 바이트를 대조한 ripgrep 15.2.0의 소스·잠금 의존성 소스·PCRE2 10.45 소스도 각각 원 라이선스를 유지합니다. Microsoft vcruntime140.dll은 별도의 재배포 약관과 원본 retail 서명 식별 정보를 유지하며 프로젝트 AGPL이 그 권리를 부여한다고 주장하지 않습니다. Windows 시스템·도구 체인 구성요소도 프로젝트 라이선스로 변경하지 않습니다.

원래 고지가 부족했던 23항목과 소스별 판단은 `source/dependencies/manifests/notice-dispositions.json`에 보존합니다. Android AAR 제조원 revision과 fxhash 추출 revision은 확정하지 못했으며 없는 wrapper 저작권 고지를 만들지 않았습니다. Cargo 게시자의 명시적 라이선스 부여·전체 원 소스와 별도 확보한 역사적·참조 고지를 구분합니다. 네이티브·바이트 동일 재빌드와 전체 복원 실행은 미실행입니다. 전체 소스 README에 복원과 실제 빌드 설정을 설명합니다. 네트워크 운영자는 실제 사용자 인터페이스에서 AGPL 제13조의 소스 제공 의무도 이행해야 합니다.
