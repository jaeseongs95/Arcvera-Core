# Arcvera-Core R42 deferred scope / R42 이관 범위

## English

The previously assigned R41 architecture work moves to R42. The current R41 is limited to source IDs, task lifetimes and dependency indexing, focused-task context projection, exclusion/reactivation, original-source lookup, exclusion history, response-level cache observations, and integration with existing compaction. Cache observation does not include structural cache redesign or adapter-confirmed TTL/expiry support. See the [R41 design](../context-index.md) and [release status](../releases/R41.md).

| R42 workstream | Boundary |
| --- | --- |
| Memory | Broader memory redesign beyond the current-thread context index |
| CodeMode | New CodeMode architecture and associated integration |
| Core-store | Broader core/storage restructuring |
| Runtime and history | Runtime/history redesign beyond R41 integration requirements |
| QSC | Previously assigned QSC work; requirements remain to be confirmed against its authoritative specification |
| Cache | Structural caching improvements |
| Refactoring | Broad architectural refactoring |
| Multiple vendors | Broader multi-vendor integration; R41's index itself remains vendor independent |

Moving scope does not establish implementation, validation, a release date, or permission to install or switch operational services. Original content, permissions, latest user corrections, active references, and ongoing work remain preservation requirements. External-memory retrieval remains disabled where disabled; unavailable retrieval does not prove absence and must not be bypassed.

## 한국어

기존에 R41로 지정했던 아키텍처 작업은 R42로 이관합니다. 현재 R41 범위는 출처 ID, 작업 수명·의존관계 인덱싱, 현재 작업 중심 문맥 구성, 활성 제외·재활성화, 원문 조회, 제외 이력, 응답 단위 캐시 관측, 기존 압축과의 연결입니다. 캐시 관측에 구조적인 캐시 재설계나 adapter가 확인한 TTL·만료 시각 지원은 포함하지 않습니다. [R41 설계](../context-index.ko.md)와 [릴리스 상태](../releases/R41.md)를 따릅니다.

| R42 작업 | 경계 |
| --- | --- |
| Memory | 현재 대화의 컨텍스트 인덱스를 넘어서는 메모리 전면 개편 |
| CodeMode | 새로운 CodeMode 구조와 관련 통합 |
| Core-store | Core·저장소의 광범위한 구조 개편 |
| Runtime·history | R41 연결에 필요한 변경을 넘어서는 runtime·history 재설계 |
| QSC | 기존에 지정했던 QSC 작업. 요구사항은 정본 명세와 대조해 확인 필요 |
| Cache | 구조적인 캐싱 개선 |
| Refactoring | 광범위한 아키텍처 리팩토링 |
| Multiple vendors | 광범위한 다중 밴더 통합. R41 인덱스 자체의 밴더 독립성은 유지 |

범위 이관은 구현·검증 완료, 발행일 확정, 설치·운영 서비스 전환 권한을 뜻하지 않습니다. 원문·권한·최신 사용자 정정·활성 참조·진행 중 작업은 계속 보존해야 합니다. 외부 메모리 조회가 비활성화된 경우 그 상태를 유지하며, 조회 불가를 정보 부재로 해석하거나 우회하지 않습니다.
